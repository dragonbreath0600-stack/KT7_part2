Отчет по выполнению задания: Покрытие тестами API эндпоинта с Pytest

В ходе работы было реализовано автоматизированное тестирование mock-сервиса JSONPlaceholder с использованием библиотеки pytest. Весь код разбит на логические сценарии, проверяющие как позитивные, так и негативные кейсы работы API.

Результаты реализации сценариев:

Сценарий 1. Добавление поста
Запрос: POST на /posts
Проверки: Возврат статус-кода 201. В теле ответа проверяется точное соответствие отправленных полей title, body и userId, а также автоматическая генерация поля id для новой записи.

Сценарий 2. Изменение добавленного поста
Запрос: PUT на /posts/1
Проверки: Возврат статус-кода 200. Проверяется корректность восстановления полей заголовка и текста. Изменения применяются к существующему дефолтному посту.

Сценарий 3. Удаление поста
Запрос: DELETE на /posts/1
Проверки: Возврат статус-кода 200, подтверждающий успешное выполнение операции удаления объекта на стороне сервера.

Сценарий 4. Проверка комментариев к посту
Запрос: GET на /posts/1/comments
Проверки: Возврат статус-кода 200. Проверяется структура ответа: данные должны возвращаться в виде списка, и этот список не должен быть пустым.

Сценарий 5. Проверка несуществующего поста
Запрос: GET на /posts/99999
Проверки: Возврат статус-кода 404. Также проверяется специфика mock-сервиса, который для несуществующих ID отдает пустой объект.


Инструкция по развертыванию и запуску проекта:

1. Установка окружения и зависимостей
Зависимости зафиксированы в файле requirements.txt.

Команды для терминала:
python -m venv .venv

Для Windows:
.venv\Scripts\activate

Для Linux и macOS:
source .venv/bin/activate

pip install -r requirements.txt

2. Локальный запуск тестов
Для запуска тестов с подробным отображением результатов в консоли используется команда:
pytest -v
